# 프롬프트 캐싱 (Prompt Caching)

## 상황
물류 배차 시스템에서 계근표 사진을 LLM API 로 판독하는 기능의 모델을, 단가가 더 비싼 새 모델로 바꾸면서 이전 모델과 비용을 비교했는데 단가 배수보다 실제 비용 차이가 작게 나왔다.
운영 배포 직후 첫 판독 로그에 입력 7,000 토큰이 그대로 찍히는 걸 보며, 말 그대로 입력 프롬프트를 캐싱해서 비용을 절감하는 구조인지, 별도 설정 없이 알아서 적용되는지, 어떤 기준으로 언제부터 적용되는지,
사진이 아침~점심에 몰리고 저녁~밤에는 띄엄띄엄 올라올 때 TTL 에 안 걸려 캐싱 효과를 못 보는 건지를 짚어둘 것.
