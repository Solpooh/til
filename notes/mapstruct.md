# 매핑 코드 생성 (MapStruct)

## 상황
물류 배차 시스템의 차량 정보에 '소속' 필드 하나를 추가했다. 엔티티와 DTO 에 필드만 더했을 뿐인데
등록·수정·상세 API 가 전부 그 값을 주고받았다 — 매핑 코드를 직접 쓴 적이 없어서, 빌드가 만들어 낸
구현 클래스를 열어 필드가 실제로 어디서 채워지는지 확인하고 넘어갔다.
왜 손으로 쓰지 않고 이 도구에 맡기는지, 생성된 코드가 경로마다 다른 모양인 이유가 무엇인지,
필드가 조용히 빠질 수 있다는 경고가 어떤 조건에서 나오는지를 짚어둘 것.
